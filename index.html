🚫 What to Never Use as a Password

  • 👤 Personal InformationNames, birthdays, addresses — easily found on social media or public records.
  • 📖 Dictionary Words"sunshine", "dragon", "football" — cracked in milliseconds by dictionary attacks.
  • 📏 Short Passwords (<8 chars)Brute‑force tools try every combination; short ones fall in seconds.
  • ⌨️ Keyboard Patterns"qwerty", "asdfgh", "1q2w3e" — among the very first guesses attackers try.
  • 🔁 Repeated Characters"aaaaaa", "111111" — drastically reduce entropy and are trivially guessed.
  • 🔄 Simple Substitutions"p@ssw0rd", "4dm1n" — well‑known tricks that cracking dictionaries already account for.
  • ♻️ Reused PasswordsA single breach exposes every account where that password is reused.
